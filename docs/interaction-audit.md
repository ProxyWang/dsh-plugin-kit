# 插件临时层交互复盘

本轮针对“收藏弹框点外部不关闭”的反馈，检查了 API、IDE、文件资源管理、Skills 和 Git 操作中的临时层。关闭逻辑集中在 [dismiss.js](../src/client/dismiss.js)，使用同一套文档级 pointerdown / Escape 监听。

## 统一规则

- 点击临时层内部不关闭，输入框、按钮、列表项照常工作。
- 左键或触摸点击外部关闭临时层，不阻止这次点击继续执行目标操作；右键不触发全局关闭。
- Esc 只处理最上层可见临时层，阻止继续冒泡到编辑器，避免顺带取消未保存草稿。输入法组合中的 Esc 不触发关闭。
- 同一工具页的触发按钮再次点击可正常收起；不同工具页的同类按钮不会被误当成当前触发器。
- 外部点击不抢回焦点；Esc 尽可能将焦点返回触发器或编辑器。
- 隐藏、断开连接的临时层不会截获其他工具页事件；卸载时释放监听器。
- 关闭只收起 UI，不提交表单、不执行删除/回退、不取消已发起的异步操作。

## 覆盖清单

| 区域 | 临时交互 | 处理 |
| --- | --- | --- |
| API | 收藏当前请求 | 外部点击/Esc 关闭，保留未保存收藏名 |
| API | 导入 curl | 外部点击/Esc 关闭，保留导入文本 |
| API | 历史与收藏列表 | 外部点击/Esc 关闭，列表项点击仍可回填 |
| API | 工具页隐藏 | 收起临时层，请求配置继续保留 |
| IDE | 命令中心 | 使用公共机制，保持内部键盘导航 |
| IDE | 快速打开 | 外部点击/Esc 关闭，修复输入框与面板重复响应键盘事件 |
| IDE | 符号列表 | 外部点击/Esc 关闭，修复重复按键处理 |
| IDE | 跳转行 | 外部点击/Esc 关闭 |
| IDE | 定义/引用位置列表 | 外部点击/Esc 关闭 |
| IDE | 引用 peek | 原有行为迁入公共机制 |
| IDE | 文件历史 | 外部点击/Esc 关闭 |
| IDE | 分支选择器 | 外部点击/Esc 关闭，分支按钮可再次收起 |
| IDE | 删除行预览 | 外部点击/Esc 关闭 |
| 文件树 | 右键菜单 | 使用公共 pointer/Esc 机制 |

| Git | 文件/目录回退确认 | 外部点击/Esc 取消确认；文件和目录确认互斥 |

| Git | stash 保存表单 | 外部点击/Esc 收起，保留表单文本 |
| Git | stash 删除确认 | 外部点击/Esc 取消；与 stash 保存表单互斥 |
| 搜索 | 全部替换确认 | 外部点击/Esc 解除确认，不执行替换 |
| Skills | 新建技能表单 | 外部点击/Esc 收起，保留名称和范围 |
| Skills | 删除技能确认 | 外部点击/Esc 取消，不执行删除 |
| Skills | 工具页隐藏 | 收起新建/删除临时层，不取消技能正文编辑 |

## 保留的持久交互

全文搜索内容页、文件内查找、Git 提交编辑器、技能正文编辑器、文件新建/重命名输入和原生 details 折叠区属于持续工作上下文，不采用“点任意外部自动丢弃编辑”的规则。打开文件、切换主模式仍使用已有导航收起逻辑和未保存保护。宿主浏览器、终端、原生文件页由 DSH 管理，本轮没有修改其内部交互。

另外修复了旧草稿末尾已有空行时，参数表仍重复添加空白新增行的问题。

## 验证与边界

- 全量运行构建、Host、客户端、搜索、嵌套工作区、父工作区、远程 Git 测试。
- 客户端测试增加可显式执行和清理 effect 的测试模式，检查真实注册的捕获监听器；覆盖主要 IDE 浮层、API 状态与草稿、技能创建、hunk 确认及监听器清理。
- 在 headless Chrome 中使用 API 源组件、测试 hook renderer 和实际 DOM/PointerEvent/KeyboardEvent 验证了 9 项收藏、导入和历史交互。该 fixture 不会发送业务请求。
- Chrome fixture 验证了浏览器事件传播和 DOM 包含关系；它不是完整 React/DSH 认证会话的端到端测试。
